## About Me

반복되는 개발 흐름을 줄이고,  
AI Agent가 작업 맥락을 이어받아 계속 작업할 수 있는 workflow를 만드는 데 관심이 있습니다.

단순히 코드를 생성하는 것보다,  
작업의 의도와 판단 기준이 다음 단계로 자연스럽게 이어지는 구조를 중요하게 생각합니다.

### Focus

> AI Agent와 함께 일하기 좋은 개발 흐름을 설계합니다.  
> 문서, 자동화, 커스텀 스킬들을 통해 반복 작업을 줄이고  
> 작업 맥락이 끊기지 않는 구조를 설계합니다.

### Interests

`Session Handoff` · `Agent Skill` · `PRD / ADR` · `Automation-first Development`
